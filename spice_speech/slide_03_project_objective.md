# SLIDE 03 — PROJECT OBJECTIVE
# Speaker: Ramim | Time: ~1:15

So — what exactly is the problem we are solving?

Spices are visually nearly identical to each other.
Cumin versus caraway — both tiny brown seeds.
Turmeric versus mustard powder — both yellow powders.
These look so similar that even trained food industry workers get confused.

And what do existing computer systems do?
They either ignore spices completely —
or group everything into one vague "seasoning" category.
That is completely useless for any real application.

This is not a small problem.
The global spice market is worth billions of dollars.
Wrong identification means wrong labeling, quality failures, and health risks.

So we set a clear goal:

Build **SpiceFusionNet** —
a multi-modal deep learning model that classifies 11 spice types
by fusing image features, texture features, and color features together.

Why multi-modal? Because no single type of information is enough.
Just like a human expert uses multiple senses —
our model uses multiple sources of information.

And the system must not just be accurate —
it must also be fast enough for real-world deployment —
in smart kitchen assistants, food quality control systems,
and retail inventory management.

The 11 spice classes we tackle:
Black Pepper, Cardamom, Cinnamon, Cloves, Coriander,
Cumin, Ginger, Nutmeg, Paprika, Saffron, and Turmeric.

Eleven spices. Eleven challenges. One unified model.
